# หน้านักเรียนและปฏิทิน

## ข้อมูลของเด็กแต่ละคน

เปิด `/admin/students/` เลือกนักเรียนจากรายชื่อ ไอดี ชื่อเล่น ชั้น/โรงเรียน และคอร์ส/เลเวลจะแสดงประกอบกัน ค้นหาได้จากทุกช่องเหล่านี้

- แก้ไอดี รหัสผ่าน ชื่อเล่น ชื่อจริง และข้อมูลเพิ่มเติมได้ในหน้าเดียว ข้อมูลเพิ่มเติมมีวันที่แก้ไขล่าสุด รหัสผ่านเดิมไม่เปิดเผย ตั้งใหม่ผ่านระบบบัญชีฝั่งเซิร์ฟเวอร์เท่านั้น (12–128 ตัวอักษร)
- การเปลี่ยนไอดีนักเรียนจะเปลี่ยนทั้งไอดีที่แสดงและบัญชีเข้าเรียน มีการกันแก้พร้อมกันและคืนไอดีเดิมเมื่อการบันทึกล้มเหลว บัญชีอีเมลแอดมินเดิมยังคงใช้อีเมล/ไอดี admin ตามเดิม
- แต่ละคอร์สมีวันเริ่ม วันต่ออายุล่าสุด (วันเริ่มรอบเรียนนี้) วันต่ออายุถัดไป และสิทธิ์เลเวล รอบหนึ่งเท่ากับเดือนปฏิทิน หากเดือนนั้นไม่มีเลขวันเริ่มให้ใช้วันสุดท้ายของเดือน
- ปิดสิทธิ์ต้องพิมพ์ไอดีของนักเรียนและยืนยันอีกครั้ง ไม่มีการลบประวัติฝึกหรือผลสอบ
- จำนวนข้อทั้งคอร์สมาจากข้อมูลราย Level เมื่อกรอกครบ จำนวนข้อที่ทำมาจากยอดรายวันที่นักเรียนบันทึกเอง สัปดาห์สถิตินับ 7 วันจากวันเริ่มคอร์ส ตารางรายละเอียดแสดงทุกสัปดาห์ กราฟแสดงล่าสุด 8 สัปดาห์

## นัดหมายและ Mock

เลือกคอร์สในส่วน "นัดหมาย" แล้วตั้งวันประจำสัปดาห์ได้ LINE เป็นวันให้นักเรียนทักอัปเดตเอง ไม่มีการจองเวลา Discord เป็นเวลาไทยครั้งละ 1 ชั่วโมง สามารถแก้วัน เวลา และพักแผนได้

เพิ่ม Mock โดยใส่ชื่อ วันเริ่มช่วงสอบ และขอบเขต Level 1–N กรอบสอบรวม 7 วัน คือ A ถึง A+6 (สิ้นสุดก่อน A+7) หนึ่งรอบเรียนวางแผน 2 ครั้ง ระบบแสดงจำนวนนัดในรอบแต่ไม่สร้างวันที่เดาให้ และอนุญาตนัดเพิ่มเติมเมื่อต้องการ นับรอบจากวันเริ่มกรอบสอบ ไม่รวมรายการยกเลิก

กรอกคะแนนและคะแนนเต็มแยกกันได้ กราฟเปรียบเทียบเป็นเปอร์เซ็นต์ และแสดงคะแนนดิบในตาราง แก้คะแนนได้โดยไม่เพิ่มจำนวนครั้งซ้ำ เพิ่มผลย้อนหลังได้โดยไม่ต้องสร้างนัดก่อน
นัดสอบเดิมแบบกำหนดเวลายังคงอยู่ตามวันที่และเวลาเดิม กรอกผลนัดเดิมได้โดยเชื่อมผลเข้ากับนัดเพื่อไม่ให้นับซ้ำ

## ปฏิทิน

- หน้าเด็กแต่ละคนมีปฏิทินเฉพาะตัว: เริ่มคอร์ส ต่ออายุล่าสุด วันนัด ช่วง Mock 7 วัน และช่วงชำระล่วงหน้า 7 วันก่อนวันต่ออายุ
- `/admin/calendar/` เป็นภาพรวมทั้งเดือน กดรายการของนักเรียนเพื่อเปิดหน้าเด็กคนนั้น การตั้งนัดและกรอกคะแนนทำที่หน้านักเรียน
- `/calendar/` ฝั่งนักเรียนเห็นเฉพาะข้อมูลตัวเอง และไม่มีเครื่องมือแก้นัด/ผลสอบ
- แถบสอบข้ามสัปดาห์หรือข้ามเดือนจะแสดงต่อกัน และมีรายการข้อความเดือนนั้นให้อ่านเพิ่มบนมือถือ
- หน้าเรียนมีข้อความแจ้ง Mock ที่กำลังจะเริ่ม นัดคุยถัดไป และกำหนดต่ออายุ ความคืบหน้าและสถิติแสดงบนมือถือ ฟอร์มเป้าหมาย/บันทึกข้อพับไว้ได้

การแจ้งเตือนเป็นข้อความในเว็บ ไม่มีการส่ง LINE/Discord หรือเก็บเงินอัตโนมัติ นักเรียนอ่านข้อมูลและผลของตัวเองได้ แอดมินเท่านั้นที่แก้ข้อมูลและกำหนดนัดได้

## การติดตั้งเพิ่มเติม

`supabase/setup/student-hub.sql` และ `student-hub-credential-lock.sql` ติดตั้งในโครงการแล้ว ฟังก์ชัน `classroom-manage-student` ใช้ตรวจสิทธิ์แอดมินก่อนเรียก Auth Admin ไม่เผยคีย์ลับหรือรหัสผ่านให้เว็บ
