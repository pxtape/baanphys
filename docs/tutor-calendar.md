# ปฏิทินติวเตอร์และแผนเรียน

เปิด `/admin/calendar/` ด้วยบัญชีแอดมิน เลือกนักเรียนและคอร์สก่อนบันทึก ข้อมูลจริงเริ่มว่าง ไม่มีการเดาวันนัด

- LINE: นักเรียนทักอัปเดตเอง ไม่มีการจองเวลา ติวเตอร์กดอัปเดตแล้ว/ยังไม่ทัก ในรายการรายสัปดาห์ (จันทร์–อาทิตย์)
- Discord: กรอกวันนัดครั้งแรกและเวลาไทย ระบบแสดงวันเดิมทุกสัปดาห์ ครั้งละ 1 ชั่วโมง กำหนดวันสิ้นสุดหรือพักแผนได้ การแก้เวลาเป็นการแก้แผนประจำทั้งหมด
- Mock: กรอกวันเวลาและระยะเวลา เลเวลสุดท้ายเริ่มจากสิทธิ์ปัจจุบันของนักเรียน บันทึกขอบเขต Level 1–N คงที่ กดนัดถัดไป +14 วันเพื่อกรอกครั้งถัดไป แล้วกดเพิ่มนัดสอบเพื่อยืนยัน กดยกเลิกก่อนสร้างใหม่เมื่อต้องการเปลี่ยนเวลา
- ปฏิทินแสดงนัดของแอดมินที่เข้าสู่ระบบ มีการกันเวลาชนทั้ง Discord และ Mock (นัดติดกันได้) นักเรียนอ่านได้เฉพาะของตัวเองและแก้นัดไม่ได้
- ลิงก์ LINE/Discord เป็นการเปิดช่องทางที่ใส่ไว้ ไม่มีการส่งข้อความ แจ้งเตือน หรือเชื่อมปฏิทินภายนอกอัตโนมัติ

## รอบเรียนและจำนวนข้อ

วันเริ่มเรียน/ต่ออายุอยู่หลังบ้านนักเรียน ต่ออีก 1 เดือนปฏิทินตามเลขวันเริ่มคอร์ส เช่น 31 ม.ค. → 28 ก.พ. → 31 มี.ค. กดบันทึกจึงยืนยัน ไม่เปลี่ยนวันที่เดิมย้อนหลังอัตโนมัติ
สัปดาห์สถิติการเรียนยังนับครั้งละ 7 วันจากวันเริ่มคอร์ส แยกจากปฏิทินนัดจันทร์–อาทิตย์

จำนวนข้อใส่ที่หัวข้อแต่ละ Level ในหน้าเนื้อหา เว้นว่างคือยังไม่ทราบ 0 คือไม่มีข้อ ระบบรวมให้เมื่อกรอกครบทุก Level ไม่ถือยอดบางส่วนเป็นยอดเต็มคอร์ส
จำนวนข้อที่ฝึกยังเป็นยอดรายวันที่นักเรียนบันทึกเอง ไม่นับซ้ำวันที่เดิมและไม่รวมการทำข้อเดิมซ้ำ
