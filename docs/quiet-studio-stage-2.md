# Quiet Studio — ขั้นที่ 2: หน้าห้องเรียน

เลือกทิศทาง B1 ตามเจ้าของเว็บ โทนอุ่น/เขียวเข้ม/ทองเฉพาะจุด ภาพบนเว็บเป็น SVG ที่สร้างสำหรับ UI ไม่ได้ใช้ภาพคอนเซปต์ทั้งแผ่นเป็นหน้าเว็บ

- ย่อการเลือกคอร์สเป็นแท็บ และยังคงแสดงคอร์สที่ไม่มีสิทธิ์แบบล็อก
- บทปัจจุบันและปุ่มเรียนต่อเป็นจุดเด่นหลัก ชื่อ เวลา จำนวนข้อ และ Level อ่านจากข้อมูลเดิม
- คงการ์ดบทเรียนแบบจัดกลุ่ม ลดความสูงของหัวหมวดและกรอบซ้อน เพิ่มเมนูเลือกหมวด
- คอมพิวเตอร์ใช้เมนูซ้ายและสรุปความคืบหน้าด้านข้าง
- มือถือเรียงคอร์ส → บทปัจจุบัน → ความคืบหน้า/เป้ารายสัปดาห์ → บทเรียน และมีเมนูล่าง
- แสดงยอดข้อและเป้าหมายเสมอ พับเฉพาะฟอร์มตั้งเป้าหมาย กราฟรายวันนับตามสัปดาห์ของระบบเดิม ไม่ใช่บังคับจันทร์–อาทิตย์
- ย้ายนัดสำคัญไว้ใกล้ความคืบหน้าด้านข้าง
- ลดเมนูซ้ำสำหรับนักเรียน และพับตัวปรับสิทธิ์ทดลองของแอดมินไว้ให้เปิดเอง

ไม่มีการเปลี่ยนฐานข้อมูล การนับข้อ สิทธิ์เรียน การปลดล็อก รายการไฟล์ หรือข้อมูลนักเรียน การปรับโปรไฟล์/ปฏิทินทั้งหน้า ภาพเฉพาะทุกบท และการฉลอง milestone เป็นงานขั้นถัดไป

การตรวจ: ชุดห้องเรียน 19 ไฟล์ / 82 tests ผ่าน, TypeScript ผ่าน, ESLint ไฟล์ที่แก้ไม่มี error/warning ตรวจพรีวิวคอม 1440px และมือถือ 390px พร้อมปุ่มเรียนต่อ ยืนยันมือถือไม่มี horizontal overflow และความคืบหน้าแสดงอยู่
